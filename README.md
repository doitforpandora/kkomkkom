# 꼼꼼이 (KkomKkom) 👶🍼

> **부부 공동 육아 기록 & 일과 시각화 플랫폼**  
> "지친 육아 속에서도 1초 만에 기록하고, 한눈에 파악하며, 완벽하게 분담하는 솔루션"

---

## ✨ 핵심 기능 (Features)

- 🍼 **원터치 수유 기록**: 모유, 분유, 유축수유, 이유식 기록 / 수유량, 먹은 시간, 마지막 수유 후 경과 시간(수유 텀) 자동 계산
- 🌙 **수면 패턴 관리**: 원터치 타이머로 낮잠/밤잠 기록 및 총 수면 시간 자동 집계
- 🧷 **기저귀 기록**: 소변, 대변(상태 및 색상 체크) 원터치 기록 및 일일 교체 횟수 모니터링
- 📝 **부부 공동 인수인계 메모**: 매일 부부/공동 양육자가 남기는 실시간 공유 노트 & 중요 사항 상단 핀(Pin) 고정
- 📊 **24시간 인터랙티브 타임라인 (Timeline View)**: 0시부터 24시까지 수면(블록), 수유(뱃지), 기저귀(아이콘)를 한눈에 보는 일간 시간표
- ⚡ **실시간 부부 동기화**: 한쪽이 기록하면 1초 이내 상대방 스마트폰에 즉시 동기화
