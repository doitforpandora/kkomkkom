📖 Supabase에서 키 복사하는 초간단 방법
  1. supabase.com/dashboard ↗ 로그인 후 아기 프로젝트 선택
  2. 좌측 사이드바 맨 아래 ⚙️ Project Settings 클릭
  3. API 메뉴 선택
  4. Project URL과 Project API Keys의 anon public 키를 복사해 붙여넣으시면 완료!

⚡ Supabase 연동 설정

가입하신 Supabase 프로젝트의 Project URL과 anon public API Key를 입력하시면, 실제 Supabase Auth 계정으로 로그인/회원가입이 작동합니다.
